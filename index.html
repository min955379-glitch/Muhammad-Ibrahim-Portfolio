Flagship Project · 01

My English Practice — English spelling and pronunciation platform

Live App (Vercel) GitHub Repository

A complete learning platform built for adult beginners whose spelling and reading are weak, starting with listening and small steps instead of fluent-reading assumptions.

Next.js 16 React 19 TypeScript Tailwind CSS 4 Drizzle ORM Supabase PostgreSQL Vercel
Content Architecture 13 fully open levels, 408 practice items (Levels 1-7 with 30 items each, Levels 8-13 with 33 each), 24 phonics patterns, six study guides, a weekly planner and a learning hub.
Core Drill Mechanics Hear a word at normal and slow speed, spell it letter by letter; a wrong letter turns red with a clear message and must be fixed before continuing; a hint ladder (slow replay, first letter, syllable breakdown) opens after repeated mistakes.
Learning Science Mistakes retry in the same session, return the next day, and follow an adapted FSRS-style schedule; mastery needs independent success on separate days.
Platform Features Dark midnight theme with System / Light / Dark toggle, female/male British voice preference applied to all speech, pronunciation and reading-aloud practice, optional microphone check used as a hint (never a strict grade), progress dashboard calculated from real saved attempts, offline-capable drills, progress export/import and cloud sync for signed-in sessions.
Verification & Testing Suite Lint, type checking and production build pass; 40 unit/database/API tests and 56 browser tests pass.

DailyMB — Android quiz helper app with a cloud backend

An independent Android app that collects the day's five "Test Your Skills" quiz answers from public websites, cross-verifies them, and presents them in a clean dark interface.

Expo SDK 51 React Native 0.74 TypeScript Zustand React Query Supabase (PostgreSQL, Edge Functions, pg_cron)
  • Backend: three scheduled fetches a day (00:05, 05:30 and 12:05 PKT); an answer is marked "verified" only when at least two independent sources agree on the same question text; uncertain answers are honestly labelled single-source.
  • App features: Home in short and full layouts, a streak system with data rewards at 5-day milestones (25 / 50 / 80 / 100 / 125 MB), 30-day history, settings, onboarding, a Check button with automatic re-check when the app returns to the foreground, and customisable notification times with a native time picker.
  • Engineering: the app ships with no database client and no login; it reads through a public read-only key and registers devices through a rate-limited Edge Function. Builds run in GitHub Actions and publish the APK to a GitHub Release. Test suite: Jest, fully passing, with strict TypeScript and lint clean.
