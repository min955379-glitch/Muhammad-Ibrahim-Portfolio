FLAGSHIP PROJECT 01 // LEARNING SCIENCE & SPEECH

My English Practice — English Spelling & Pronunciation Platform

A complete learning platform built for adult beginners whose spelling and reading are weak, starting with listening and small steps instead of fluent-reading assumptions.

  • Content: 13 fully open levels, 408 practice items (Levels 1–7 with 30 items each, Levels 8–13 with 33 each), 24 phonics patterns, six study guides, a weekly planner and a learning hub.
  • Core Drill: Hear a word at normal and slow speed, spell it letter by letter; a wrong letter turns red with a clear message and must be fixed before continuing; a hint ladder (slow replay, first letter, syllable breakdown) opens after repeated mistakes.
  • Learning Science: Mistakes retry in the same session, return the next day, and follow an adapted FSRS-style schedule; mastery needs independent success on separate days.
  • Features: Dark midnight theme with System / Light / Dark toggle, female/male British voice preference applied to all speech, pronunciation and reading-aloud practice, optional microphone check used as a hint (never a strict grade), progress dashboard calculated from real saved attempts, offline-capable drills, progress export/import and cloud sync for signed-in sessions.
  • Verification: Lint, type checking and production build pass; 40 unit/database/API tests and 56 browser tests pass.

MOBILE APP 01 // EXPO SDK 51 · REACT NATIVE 0.74 · SUPABASE

DailyMB — Android Quiz Helper with Cloud Verification

An independent Android app that collects the day's five "Test Your Skills" quiz answers from public websites, cross-verifies them, and presents them in a clean dark interface.

  • Scheduled Cloud Backend: Three scheduled fetches a day (00:05, 05:30 and 12:05 PKT) via Supabase Edge Functions and pg_cron; an answer is marked "verified" only when at least two independent sources agree; uncertain answers are honestly labelled "One source only".
  • App Features: Home in Short and Full layouts, a Streak system with data rewards at 5-day milestones (25 / 50 / 80 / 100 / 125 MB), 30-day history, foreground auto-recheck, and customisable notification times (05:30 to 08:00 + 8:00 PM second reminder) in English & Urdu.
  • Engineering & Security: Ships with no database client and no login; reads via public read-only key and registers devices through a rate-limited Edge Function. Signed APK built in GitHub Actions with Jest tests passing.
